# 缓冲机制
```cpp
    fprintf(stderr, "Hello");
```
- linux:
    - stdout: _IOLBF 行缓冲(cout 1号流, clog 2号流)
    - stderr: _IONBF 无缓冲(cerr， 2号流)
    - fopen:  _IOFBF 完全缓冲(fstream)
    - 完全缓冲指只有超出缓冲区大小(BUFSIZ, linux上8192, windows上512, 进入内核态非常频繁)
- MSVC:
    - stdout: _IOLBF 无缓冲
    - stderr: _IONBF 无缓冲
    - fopen:  _IOFBF 完全缓冲
    - windows上cout,clog,cerr全部都是无缓冲的,因为根本没有实现行缓冲

- 因此linux终端略快于windows终端，因为MSVC整个流都没有实现行缓冲，每次输出字符都需要进入内核态调用write
```cpp
    fflush(stdout);    // 手动刷新流
    _exit();           // 快速退出，不调用回调
    exit();            // 调用回调
```

- 2>&1, 把2号流强制绑定到1号流上(linux终端)
- linux clog需要与C语言的stderr同步，调用std::ios::sync_with_stdio(false)关闭同步后为行缓冲,cout变成完全缓冲
